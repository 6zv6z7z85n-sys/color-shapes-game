Создавай фигуры из точек и захватывай территорию.

Как играть

Правила:

  • Каждый игрок ходит по очереди - один ход = одна точка
  • Точки идут подряд без пропусков между ними
  • На одну клетку может быть только одна точка (любого цвета)
  • Когда цепь замыкается в фигуру из 3+ точек - территория захватывается
  • Точки остаются на доске для визуала
  • Ход автоматически переходит следующему игроку
